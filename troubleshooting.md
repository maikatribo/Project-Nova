Part 2: Git Troubleshooting & Emergency Fixes

1. Oops, Wrong file 'git restore --staged .env'

2. Typo in the Commit Message 'git commit -amend -m "Fixed authentication typo"

3. Forget a file 'git add style.css' 'git commit --amend --no-edit'

4. I hate these changes 'git restire index.hmtl'

5. Wrong branch 'git branch new-feature' 'git reset HEAD~3 --hard' 'git checkout new-feature'

6. Detached Head 'git switch -c recovery-branch'

7. Undo a pushed mistake 'git revert <buggy-commit-hash>

8. Accidental deletion 'git reflog' 'git branch <deleted-branch-name> <commit-hash>'

. Ghost files 'git add -u'

10. Pushed to the void 'git push origin --delete testing-junk'
